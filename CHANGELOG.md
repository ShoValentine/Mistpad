# Mistpad 1.0.0

Initial Retail release for handheld touchscreen play.

- Drag windows in from all four screen edges, with animated opening and closing.
- Enlarged single-row micro menu, including Contacts and Mistpad Settings.
- Configurable left and right window assignments.
- Touch-friendly combined bags with scrolling, configurable layouts and item sizes, optional search, dynamic contents and long-press item actions.
- Fixed handheld window scales, applied before side-panel slides.
- Enlarged talent canvas with scrolling and separate class/specialization pages.
- Touch-friendly Spellbook and Specialization layouts.
- Gameplay HUD remains unchanged.

Standalone addon. Disable WoWU before using Mistpad.
